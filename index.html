The ClawSolved Platform

ClawForge generates skills the right way. ClawProof validates them against the real world. ClawShield makes the proof tamper-proof. Used together, they are the missing quality and security infrastructure for the OpenClaw ecosystem.

ClawForge

Generate

Takes a service, API, or tool and generates a correctly-structured, dependency-aware SKILL.md from live documentation — not from memory, not from a single LLM pass.

  • → Scrapes live documentation, changelogs, and official examples automatically
  • → Builds a dependency graph: prerequisites mapped, parameters typed, error paths documented
  • → Generates valid YAML frontmatter with accurate requires declarations that pass ClawHub’s security analysis cleanly
  • → Instructions written as runbooks, not marketing copy: deterministic steps, stop conditions, explicit output format
  • → Local-first pipeline — no external LLM API, nothing leaves your machine
ClawProof

Validate

Installs the generated skill into a clean OpenClaw sandbox and runs it against the real API it claims to operate. Pass/fail, not opinion.

  • → Sandboxed OpenClaw instance executes each skill node’s test scenario
  • → Live API validation: Todoist, GitHub, Slack, Linear, Stripe sandbox, Notion, Airtable
  • → Confidence score per node (0.0–1.0) based on actual execution pass rate
  • → Flags prompt injection vectors, undeclared environment variables, and metadata mismatches
  • → Human review gate on every failure — no unvalidated node ships, ever
ClawShield

Certify

Signs every validated skill with a cryptographic certificate recording what was tested, when, against which API version, with what result.

  • → Ed25519 certificate bundled with every published skill
  • → Records: skill hash, API version tested, test date, per-node confidence scores, ClawSolved public key
  • → Tamper detection: any modification to the SKILL.md after signing breaks the certificate — detectable before install
  • → Directly addresses the ClawJacked vulnerability class: skill content confirmed unmodified since validation
  • → Verification via CLI: clawsolved verify <skill> or public HTTPS endpoint

The three tools are available individually or as an integrated pipeline. The integrated pipeline is what most teams want: input a service name, get a validated, signed, ClawHub-ready SKILL.md in minutes.

ClawForge — Under the Hood

How a skill is actually built

Five stages. Four automated. One requires human judgment — permanently, by design. The human gate is what separates ClawSolved skills from everything else on ClawHub.

01

Scrape

Playwright navigates official documentation, API references, changelogs, and example repos. Clean Markdown extracted and organised by section. Runs overnight against any public URL.

Automated
02

Graph

Local LLM constructs a directed acyclic dependency graph. NetworkX validates structure: no cycles, no isolated nodes, all prerequisite chains complete and explicit before proceeding.

AI + schema validation
03

Enrich

Each node receives: executable test scenario, documented edge cases, accurate requires declarations, cross-references to adjacent nodes. Frontmatter validated against ClawHub schema.

Automated
04

Validate

Sandboxed OpenClaw executes each test scenario against the real API. Failures trigger human review. Reviewer corrects or removes — no failed node ships. Confidence score assigned.

Human gate — permanent
05

Sign + Publish

ClawShield certificate generated and bundled. Skill published to ClawHub with ClawSolved-verified badge. Version tracked. Auto-rescan triggered when API docs change.

# Todoist Task Management

## Dependency map
Node order: auth-check (1) → project-list (2) → task-create (3) / task-complete (4) / task-move (5)

## Node 3: Create a task
Confidence: 0.96 | Tested: REST v2 | Last validated: 2026-03-10

When the user asks to add, create, or schedule a task:

1. Check TODOIST_API_KEY is set. If missing, respond: "I need your Todoist API key. Add TODOIST_API_KEY to your environment."

ClawShield

Proof that travels
with the skill.

ClawShield directly addresses the attack vector that ClawHavoc exploited: skills that look legitimate but have been modified after creation, or built specifically to deceive. Every ClawSolved skill is signed with an Ed25519 certificate the moment it passes validation.

The certificate records the exact state of the skill at validation time. Any modification to the SKILL.md after signing — even a single character — breaks the certificate. The breakage is detectable before installation, before the skill touches your agent.

  • →Tamper detectionEd25519 signature covers the entire SKILL.md. Modified skills fail verification before install. Directly closes the ClawJacked vulnerability class documented by security researchers in February 2026.
  • →API version pinningCertificate records the exact API snapshot date tested against. When the API releases a breaking change, the certificate flags as potentially stale — prompting re-validation before continued use.
  • →Prompt injection attestationCertificate records the result of prompt injection scanning at validation time. A clean certificate means no injection payloads were present when the skill was tested.
  • →Public verification endpointAnyone can verify any ClawSolved certificate via CLI or HTTPS. No account required to check a certificate. Verification is always free and takes under two seconds.
